# Portfolio

Cristian Brinza's personal portfolio, live at cristianbrinza.com. Vite, React and TypeScript, Yarn Classic, Node 22.

Read `../handoff/portfolio.md` first. This project keeps its own design: Gradient tokens and the Shades brand don't apply here. The Shades rulebook's engineering, writing and legal rules do.

Commit with `git -c user.email=cristian.brinza@shades.md commit`, conventional and one logical change each, with no AI attribution. Deploy with `yarn deploy` after `yarn build` passes.
